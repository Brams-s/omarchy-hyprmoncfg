# hyprmoncfg panel 2.8.0

You can now hide the panel's bar icon and open the editor from your own menu instead, and the panel stays expanded when you preview a layout. It works with [hyprmoncfg 1.19.0](https://github.com/crmne/hyprmoncfg/releases/tag/v1.19.0) or newer; [1.23.0](https://github.com/crmne/hyprmoncfg/releases/tag/v1.23.0) is recommended.

![The Omarchy bar with the Display icon between wifi and volume, and with showBarIcon false, where wifi and volume sit side by side](https://raw.githubusercontent.com/crmne/omarchy-hyprmoncfg/v2.8.0/design/releases/2.8.0-bar-icon.png)

*Rendered offscreen with Omarchy's own bar icons and theme.*

## New

- **The bar icon is optional** ([#21](https://github.com/crmne/omarchy-hyprmoncfg/pull/21)). Set `"showBarIcon": false` on the `crmne.hyprmoncfg` bar entry in `~/.config/omarchy/shell.json` and the icon's slot collapses, so you don't get two Display icons when you open the editor from Omarchy's Display menu. The editor, its IPC route and the preview guard stay loaded; open it with `omarchy-shell shell summon crmne.hyprmoncfg '{}'`. The default still shows the icon. By @keylimesoda.

## Fixed

- **The panel stays expanded when a preview starts** ([#27](https://github.com/crmne/omarchy-hyprmoncfg/issues/27)). A preview that remaps displays rebuilds Omarchy's bars, and the panel inside them came back compact, with the small Keep/Revert bar instead of the full banner. Reported, fixed and tested live by @athn-mestrella.
- **Preview & save says when a profile name is missing** ([#30](https://github.com/crmne/omarchy-hyprmoncfg/issues/30)). The button used to stay disabled, with nothing to say why, until you typed a name, so it looked broken. It now shows "Give this layout a profile name before previewing it." and puts the cursor in the name field. Reported by @Knutsi.

## Known limitations

- **With the icon hidden, the editor isn't in the bar's numbered panel shortcuts** or in Tab switching between panels, since both count visible icons. Open it with the summon command.
- **Omarchy has no Display-menu extension slot yet.** Adding the editor to that menu means a user-owned copy of it, as the README explains.

## What's tested

Node tests (183), offscreen QML tests (21), a new offscreen test of the real bar widget with the icon shown and hidden (7), and plugin validation pass. The image was rendered offscreen. Opening the editor from a hidden icon was tested by @keylimesoda on a two-display desktop, including after a shell restart; the expanded-panel fix was tested live by @athn-mestrella. The bar's open-panel mark with a hidden icon is covered by tests, not yet seen on hardware.
