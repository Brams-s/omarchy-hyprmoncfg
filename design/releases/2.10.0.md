# hyprmoncfg panel 2.10.0

Set terminal text size independently, switch source installs to faster prebuilt updates, and get the correct theme colors on Qt 6.12. Requires hyprmoncfg 1.24.0 or newer; [1.25.0](https://github.com/crmne/hyprmoncfg/releases/tag/v1.25.0) is recommended for sensor calibration, fixed-panel touch alignment, and wake recovery.

![The expanded panel with working theme colors in a light palette](https://raw.githubusercontent.com/crmne/omarchy-hyprmoncfg/v2.10.0/design/releases/2.10.0-light.png)

## New

- **Faster updates without compiling Go.** Source-package users get **Switch to prebuilt package** in the compact panel. It opens an interactive package-manager terminal, verifies the replacement, then restarts the daemon. Profiles stay in place. Fresh installs already use hyprmoncfg-bin; ordinary upgrades preserve the installed package, including hyprmoncfg-git. The action stays hidden during edits, previews, and service work. By @crmne.
- **Size terminal text independently.** The new Terminal slider controls Alacritty, Ghostty, Kitty, and Foot without changing the shell or GTK text size. Pointer and keyboard controls use the same stops. It uses Omarchy's command when available and a bundled copy until Omarchy ships it. By @crmne, using the command from [omacom/omarchy#15896](https://github.com/omacom/omarchy/pull/15896).

## Fixed

- **Theme colors work on Qt 6.12.** Qualified references keep Qt's new Color type from shadowing Omarchy's theme singleton throughout the panel. By @crmne; thanks @osteotek for [#36](https://github.com/crmne/omarchy-hyprmoncfg/issues/36).
- **Unknown daemon builds are visible.** An installed release paired with an unknown running daemon offers Restart daemon and a reminder to check its service path. Unversioned development builds no longer satisfy the minimum-version check. By @crmne; thanks @xpusostomos for the follow-up to [#34](https://github.com/crmne/omarchy-hyprmoncfg/pull/34).
- **Auto's pause during preview is explained.** Confirmation now says Auto rotation resumes after Keep. Sensor calibration and fixed-panel touch fixes are available in backend 1.25.0. By @crmne; thanks @xpusostomos for [crmne/hyprmoncfg#90](https://github.com/crmne/hyprmoncfg/issues/90).

## Known limitations

- Text size also changes terminal fonts proportionally, so a separate Terminal choice lasts until the next Text size change. Foot uses the new size in new windows or after restart.
- Sensor calibration and rotation direction remain backend CLI controls.
- The package switch was tested with stub package-manager commands, not by replacing the host's installed package. Physical 2-in-1 rotation was not tested.

## What's tested

All 219 Node tests, 21 panel QML tests and 20 bar QML tests pass, along with qmllint and plugin validation. Actual before-and-after captures cover compact (430x680) and expanded (1177x680) layouts in dark and light themes on Qt 6.12. Installer tests exercise success, cancellation, a package manager that leaves the source package installed, stale package detection, and development-package preservation. Terminal tests use temporary config files. No live monitor layout was changed.
