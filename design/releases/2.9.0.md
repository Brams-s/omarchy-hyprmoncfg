# hyprmoncfg panel 2.9.0

Changing a monitor's refresh rate is now one click, scales that would look blurry say so, and 2-in-1s and tablets get automatic rotation with a lock. It needs [hyprmoncfg 1.24.0](https://github.com/crmne/hyprmoncfg/releases/tag/v1.24.0) or newer, and offers the update when an older one is installed.

*Rendered offscreen with sample displays and Omarchy's own controls and theme.*

## New

- **Resolution and Refresh are separate controls.** Mode used to be one dropdown with every resolution and rate, 36 entries for a 4K 144 Hz monitor. Resolution now lists each resolution once, largest first, and Refresh shows the rates that resolution offers as pills, so 60 Hz versus 144 Hz is one click. Changing the resolution keeps the rate when it can. The keyboard reaches Refresh right after Resolution, and profiles store the same mode as before.
- **Automatic rotation for 2-in-1s and tablets** ([crmne/hyprmoncfg#90](https://github.com/crmne/hyprmoncfg/issues/90)). When hyprmoncfg reports an orientation sensor, a built-in panel's Rotation row starts with **Auto**, which turns the panel with the device and keeps its current rotation as upright, shown in the header, for example "Upright 270°". Beside Auto, the toggle becomes **Lock**, which holds the current rotation; the header then says "Locked", or "Upright while folded" on a convertible folded as a laptop. Choosing a fixed rotation turns Auto off. Reported by @xpusostomos, whose first attempt was #34.
- **Custom scales.** More now ends with **Custom…**, where you type any scale. hyprmoncfg says whether it is sharp and offers the closest sharp one, with the same numbers and words as the TUI; Enter applies the sharp one and Esc cancels.

## Fixed

- **Scales that give fractional pixels say so.** A scale that isn't sharp is marked **⚠ Blurry** on its pill and in the SCALE header, not by colour alone. The panel now asks hyprmoncfg instead of repeating its maths.
- **The Scale row stays still while you step.** A scale that isn't one of the presets shows on the More button instead of adding a pill and narrowing the rest.
- **The bar icon keeps its full size when hyprmoncfg is connected** ([#33](https://github.com/crmne/omarchy-hyprmoncfg/pull/33)). The connected badge counted towards the icon's size and shrank it to about 12 px against Omarchy's 14. By @EyasDmour.
- **Reset buttons never cover a choice.** A row whose choices leave no room for its reset shows it in the header, as Scale already did. This happened on Rotation once Auto was added, beside a portrait panel.

## Known limitations

- **The rotation direction** is set with `hyprmoncfg rotation direction reversed`, for a device whose sensor turns the wrong way; the panel has no control for it.
- **To flip a panel set to Auto,** choose a fixed rotation, set Flipped, then choose Auto again: beside Auto the toggle is Lock.

## What's tested

Node tests (206), offscreen QML tests (21 and 20), qmllint and plugin validation pass. Before and after captures of the real panel with sample displays, rendered offscreen in dark and light themes, cover each change. On a desktop with an MSI MPG321UR-QD and an LG 16MR70, Resolution and Refresh, the Scale row, Custom… and the Blurry marker were tried by hand in the live shell, which found the Refresh row running off the panel with seven rates; it now wraps onto a second line. Automatic rotation has not run on a real 2-in-1 yet.
